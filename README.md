# Devifly

Sitio web y portafolio de **Devifly** — agencia de desarrollo web moderno (landings, invitaciones digitales, menús, catálogos, reservaciones y software a medida).

## Stack

- **Vue 3** (Composition API, `<script setup>`)
- **Vite 8**
- **Tailwind CSS v4**
- **Vue Router 4**
- **Vue I18n** (es / en)
- **Lucide Vue Next**

## Estructura

- `src/views/` — páginas principales
- `src/views/demos/` — demos interactivas por producto
- `src/views/landings/` — landings comerciales
- `src/components/` — UI reutilizable
- `src/data/` — catálogo, SEO, contenido de landings
- `src/assets/` — imágenes (p. ej. foto del founder)
- `public/` — favicon, cursores, OG image, robots, sitemap

## Desarrollo local

```bash
npm install
npm run dev
```

Abre `http://localhost:5173`.

## Producción

```bash
npm run build
npm run preview
```
